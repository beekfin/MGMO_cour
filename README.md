# MuZero с непрерывным пространством действий

Начальный этап курсовой работы.

Автор: Соколов Никита Андреевич.
Руководитель: Кудрявцев Сергей Александрович.

## Что выполняет программа

Программа запускает среды маятника `Pendulum-v1` и автомобиля
`MountainCarContinuous-v0`. Для каждой среды она создаёт сетку из пяти
допустимых действий, выполняет три эпизода со случайным выбором действий
и записывает наблюдения о запуске в отчёт.

Отдельно реализована нейронная модель MuZero: она преобразует наблюдение
во внутренний вектор, по вектору и численному действию предсказывает
следующий вектор и награду, затем выдаёт оценки действий и ценность.
Есть расчёт цели ценности по фрагменту траектории с обработкой завершения
задачи и внешнего ограничения времени.

В этой версии сеть не выбирает действия и не обучается. Поиск по дереву,
буфер траекторий, полный цикл обучения, адаптивная дискретизация и
Sampled MuZero ещё не реализованы. Это исходный код начального этапа,
описанного в приложениях к РПЗ.

## Состав

- `muzero_continuous/actions.py` — сетка и преобразование индекса в численное действие.
- `muzero_continuous/model.py` — функции представления, динамики и предсказания.
- `muzero_continuous/targets.py` — расчёт цели ценности.
- `muzero_continuous/check_stage1.py` — запуск обеих сред и проверка вычислений сети.
- `tests/test_stage1.py` — девять автоматических проверок компонентов.
- `requirements-stage1.txt` — версии зависимостей проверенного окружения.
- `artifacts/muzero_stage1/report.json` — сохранённый отчёт, использованный в РПЗ.

## Запуск

Команды выполняются из корневой папки репозитория `MGMO_cour`.
Проверенная среда использует Python 3.14.9; точные версии библиотек
указаны в файле зависимостей и сохранённом отчёте.

```bash
git clone https://github.com/beekfin/MGMO_cour.git
cd MGMO_cour
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-stage1.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m muzero_continuous.check_stage1 --out artifacts/new_run/report.json
```

В Windows после создания окружения вместо `.venv/bin/python` используется
`.venv\Scripts\python.exe`.

Команда проверки записывает новый отчёт в `artifacts/new_run/report.json`,
сохраняя исходный отчёт для сопоставления с РПЗ. Параметры `--episodes`
и `--seed` задают число эпизодов и начальное значение генераторов.

Девять проверок охватывают сетку действий, форму данных, вычисления обеих
конфигураций сети, прохождение градиента и правила цели ценности. Начальный
запуск измеряет отдельные вычисления необученной сети. Его время не является
временем поиска или обучения MuZero, а суммы наград относятся к случайному
управлению.
